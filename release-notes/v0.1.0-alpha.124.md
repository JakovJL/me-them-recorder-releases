# Me/Them Recorder 0.1.0-alpha.124

Cumulative alpha release from 0.1.0-alpha.100 through 0.1.0-alpha.124.
Local-first audio recorder: microphone + system/loopback capture,
WhisperX/Groq transcription, optional pyannote speaker diarization,
and a me/them split — all on Windows with an NVIDIA GPU.

## Highlights

### Transcription
- **Import & batch transcription:** transcribe any chosen audio file (or a
  batch of files) through the Room pipeline, with optional me/them speaker
  split. Each batch result auto-saves to `output/` under a filename-derived
  stem, with per-file failure isolation.
- **Diarized online meeting mode:** the microphone transcribes as `me` while
  loopback (remote voices) run through Room diarization and get stable
  `speaker_N` identities.
- **Staged status & honest progress:** phase labels, percent progress, and a
  titlebar line report the real transcription stage; background progress no
  longer pretends to advance while idle.
- **Analysis follows the transcript language** for summaries and Q&A.

### Meetings & workspace
- **Meetings calendar** with day filtering; dialogs, buttons, and toasts
  unified across the app.
- **Stable numbered speaker identities** (Room/import) with a unified
  per-speaker naming editor, an honest single-speaker state when diarization
  is absent, and an explicit warning that preserves the plain transcript
  when speaker separation fails.
- **Editable meeting title and interlocutor name** during recording, persisted
  with the final transcript; the same fields edit an opened saved meeting.
- **Themed confirm dialogs** replace every native `window.confirm` so popups
  follow the studio/indigo style and the dark/light theme.

### Reliability
- **Cancellable summary & Q&A** generation (cooperative abort at the next
  checkpoint). The cancel event is set under the state lock so a late
  worker can never publish a result that clobbers the cancelled `idle` state.
- **Atomic file writes** (temp file + same-directory rename) for transcripts,
  analysis, meeting metadata, Markdown export, and `.env` token deletion — a
  crash or interrupted write can no longer truncate a saved meeting or wipe
  other tokens.
- **Fixed the update install (`код 5` / access denied):** the installer now
  force-closes any running `MeThemRecorder.exe` in its `PrepareToInstall` step
  before touching files, and the in-app updater launches a detached waiter
  that waits for the running app to exit first. Me/Them Recorder hides in the
  tray on close, so Inno Setup's own close-apps handling could never end the
  process — that left an exclusive lock on the .exe and the install aborted
  with `DeleteFile failed; code 5`. The Setup-side fix applies to **every**
  update path: manual double-click, the old built-in updater on v100..v123,
  and the new detached waiter, so a wedged/tray-hidden process can never keep
  the binary locked again.

### UI
- **Studio-console recorder redesign:** tape transport, VU meters, amber lamp
  accent, and a neon focus-wave dial.
- **Appearance settings tab** with studio/indigo styles and a theme-aware logo.
- **Full UI localization in 15 languages** (frontend-owned translation,
  locale-agnostic backend message keys).

## Installing

Run `MeThemRecorder-0.1.0-alpha.124-Setup.exe`. The installer is per-user (no
UAC) and defaults to `%LOCALAPPDATA%\Programs\MeThemRecorder`; the destination
page is always shown.

The bundled Setup is the lightweight app only. On first run, the app prompts
to download the separately versioned, SHA-256-verified Local Runtime
(Torch/CUDA/WhisperX/pyannote) if local transcription or Room diarization is
selected; Call/Groq-only setups need no download.
