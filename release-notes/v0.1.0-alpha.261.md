# Me/Them Recorder 0.1.0-alpha.261

Cumulative alpha release from 0.1.0-alpha.152 through 0.1.0-alpha.261.
Local-first Windows recorder for microphone and system audio, transcription,
speaker-aware meeting notes, summaries, and Q&A.

## Local Runtime v4 (new local GPU stack)

- **WhisperX transcription and pyannote diarization moved to the v4 stack:**
  torch 2.8 on CUDA 12.6, whisperx 3.8.6, and pyannote.audio 4 with the
  community-1 speaker-diarization pipeline — better speaker assignment and
  faster diarization.
- Frozen-runtime diarization was fixed for the new stack, so the packaged
  worker returns speakers instead of a transcript-only fallback.
- The v4 Local Runtime is an optional, consent-gated download; already
  installed v3 runtimes keep working, and app updates keep reusing the
  installed runtime instead of re-downloading it.

## Transcription engines

- **Nemotron streaming engine (new local engine):** live transcription with
  independent `Me`/`Them` decoder states that stays resident during recording,
  plus a faster-than-realtime offline replay of the saved tracks after Stop.
- **Parakeet / GigaAM engine (new local engine):** final-only offline
  transcription decoded by the bundled native Live Runtime — the recording
  path no longer needs the Torch stack for these models.
- **Local Runtime line:** verified, resumable runtime and model downloads,
  compatible-version selection, and app updates that reuse the already
  installed runtime instead of re-downloading it.

## Analysis: summaries and Q&A

- **Streaming summaries with a live phase card:** provider Server-Sent-Events
  reach the UI as reasoning/writing phases, with cooperative cancel, an
  idle-gap watchdog, and honest timeouts that scale with the payload.
- **Four analysis providers:** OpenRouter, Groq, Cerebras, and a Custom
  OpenAI-compatible server — with per-model chunk ceilings so free-tier
  rate limits stop breaking long transcripts, reasoning on/off (including a
  reasoning-effort level for Cerebras), and real provider token usage and
  cost reported in the result footer.
- **Named Custom API profiles:** several endpoints with their own keys,
  saved without requiring a live server, one consistent activate button per
  provider, and the active profile visible on the provider pill and in the
  summary footer.
- **Summary Save state:** once the summary is on disk, the Save button shows
  a `Saved` state and disables instead of inviting a redundant write.

## Glossary v2

- A unified templates hub and editor with a 250-term budget and visible
  prompt accounting (priority by position, per-term exclusion).
- Auto-apply that rewrites spelling variants into saved transcripts with a
  per-term card and one-level Undo.
- AI drafting of term sets, an external-AI paste flow for any chat model,
  and "generate more" that appends deduplicated terms.

## Meetings, history, and playback

- **Recency filter (All / Week / Month / 3 months)** composed with text
  search and the calendar heat map. The history tab now opens on the week
  window, and any calendar day or search that needs older meetings widens
  the window automatically instead of dead-ending.
- **Timestamp double-click seeks** the built-in source-audio player; the
  player streams the meeting audio from the app.
- **Participation tab:** talk-time shares per speaker with distinct,
  stable colors for diarized `speaker_id`s.
- Per-meeting provenance (engine, model, quality, method) recorded in the
  meeting sidecar and shown in the workspace; meta editing (title and
  interlocutor) including mid-recording.
- Transcript rows render as paragraphs across the full row width, and the
  workspace drops decorative icons where a label already speaks.

## Recording reliability and data safety

- **Single-instance guard:** a second launch restores the running window
  instead of silently becoming a second writer.
- **Settings durability:** every save keeps backup generations, a lost or
  damaged `settings.json` is recovered from them on boot, and a fresh
  first-launch snapshot is refused over a lived-in file (with a rescue
  copy) instead of silently replacing it.
- Stop retains the frozen in-memory recording if the source-audio write
  fails, offers an explicit Retry, and refuses normal exit until
  persistence succeeds; draft recovery covers failed final passes.
- Mistimed transcript segments (end before start) are healed on load
  instead of hiding whole meetings; imports are dated in the local time
  zone.

## Onboarding and platform

- **First-run guide:** OS-language autodetect, a mic-first scenario path
  with local/cloud setup plans, and consent-gated model downloads.
- **In-app updates** from the public GitHub Releases repository with
  SHA-256 verification and resumable downloads. A found update is
  re-offered on every launch until it is installed, and every update
  check is logged (only an up-to-date result claims the daily check
  window). The install handoff itself is fully logged too: every waiter
  step plus the Setup's own Inno trace land in
  updates/update-install.log, and errors are no longer swallowed.
- **Local MCP server** exposing read-only saved-meeting queries to external
  assistants (Claude Desktop, Cursor, ZCode, OpenCode, Codex CLI) with
  in-app client registration.
- UI localized in 15 languages; Windows tray flow and configurable global
  start/stop hotkeys.

## Model management

- The Models tab is an inventory: local and streaming models with quant
  families, download/delete, VRAM guidance, and engine selection in one
  place; the live model catalog downloads are verified and resumable.
