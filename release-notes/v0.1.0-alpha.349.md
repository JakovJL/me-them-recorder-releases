# Me/Them Recorder 0.1.0-alpha.349

Changes since **0.1.0-alpha.344**.

- Faster Nemotron and native (Parakeet/GigaAM) transcription on hyper-threaded CPUs: the native runtime now runs one thread per physical core instead of two per core. That doubled-up pool stalled whenever other apps were busy and let the live transcript fall tens of seconds behind on long calls. On a real Call recording on a 4-core/8-thread laptop the live path ran 2–4× faster (RTX/Vulkan real-time factor 0.39–0.73 → 0.15–0.23, CPU-only 1.18 → 0.39) and the post-Stop Nemotron final about 2.3× faster, with byte-identical text. The native runtime itself is unchanged (no new download). The log line `live: streaming model loaded … cpu_affinity=…` shows the mask in use.
- Ghost transcript keeps a sticky bottom. After you scroll up to reread, it returns to the latest line by itself once new text has arrived and you have left it alone for 6 seconds, then follows again. Silence never pulls you back. Holding the mouse button (scrollbar drag, selecting) or keeping a text selection postpones the return. It returns smoothly unless Animations are off or Windows asks for reduced motion.
- Settings and first-run guide: every Yes/No checkbox carries the setting's name and description for screen readers. The floating Settings ✕ no longer sits on the first line of content. Meeting/interlocutor and Ghost model-field placeholders are short enough not to clip in all 15 languages. The "Animations" description no longer reads backwards next to its Yes/No state. The idle stage card names the Interview mode instead of "Call".
- Interview/Ghost answers the question that was actually asked: each press sends the interviewer's related speech and the gray live fragment separately, the model resolves the whole question in the same request, and Ghost shows "Understood as …" before the answer streams. A candidate's "uh-huh" in the interviewer's pause no longer cuts the question in half.
- Answers may build plausible details when the preparation has nothing ready, but keep stated projects, employers, dates, stack and number categories intact.
- Full now develops the finished Quick answer instead of writing an independent one: it waits for Quick up to 5 seconds, then runs on its own if Quick is late, failed or was cancelled. A corrected Quick is flagged "Refined answer".
- A new request no longer shows the previous answer as if it were the new one: the older text stays visible once, labelled "Previous answer" or "Previous attempt", and an interrupted text is marked "Not finished".
- Each Interview meeting keeps a local trace (`<stem>.interview.trace.jsonl`) that links every press to the captured question, the provider request and the displayed answer. It follows the saving choice, is deleted with the meeting, and never leaves the computer.
- Cancel really stops summary, Q&A and Interview requests: the provider connection is closed instead of waiting for the next streamed line. Background summary and Q&A chips have a Cancel button, also on another meeting, during a recording and in History; both chips show at once when both jobs run. A Q&A answer that finishes while another meeting is open is saved to its own meeting's chat instead of being discarded.
- Interview/Ghost Stop releases the live engine for a fresh manual Start without waiting for the final live drain or a full offline replay. Source audio saves independently in the background, following the existing saving preference.
- Background save failures retain their recording buffers, show Retry in Ghost and the normal window, and protect exit/deletion. Older save completion and runtime callbacks cannot replace a new capture.
- Prepare restores saved CV, position, instructions and language after Interview → Call → Interview. Unsaved edits and rejected-save input remain intact.
- Start visibly reflects stopping or an independently running transcription instead of appearing available and doing nothing.
- Choosing the Interview mode on Parakeet, Whisper or Groq now switches transcription to the streaming Nemotron model and says so (with Nemotron missing, it offers the download first); picking a non-streaming model while in Interview returns the mode to Call with a notice. Previously Interview silently disappeared on those engines.
- History cards show Copy, Rename and Delete again: they stay visible (quiet until the row is hovered or focused) instead of appearing only on hover, which the desktop window did not always deliver.

Local verification uses simulated capture/runtime/persistence, a local socket server for cancellation, real browser UI and native-runtime replays of saved Call recordings. The canonical build ran all tests (1812 Python, 991 frontend) and a silent install/uninstall of this exact Setup. A live interview rehearsal, physical microphone/loopback, GPU reload, hybrid P/E-core CPUs and conferencing acceptance remain pending.
