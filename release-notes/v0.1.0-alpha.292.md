# Me/Them Recorder 0.1.0-alpha.292

Changes since the previous published release, **0.1.0-alpha.266**.

## Interview suggestions (opt-in, Call only)

- Opt-in answer suggestions on Call recordings. CV, position, and preferences are saved locally and frozen at recording Start.
- One Get answer press after interviewer text is committed returns a short first-person answer with expandable detail. No question input is required.
- Optional clarification lives in a blank closed details block (≤4,000 chars); empty/whitespace falls back to the conversation, and a long automatic turn never blocks.
- One self-contained provider request per press carries the full conversation plus prior suggestions; prior suggestions stay separate from actual speech, and the model finds the latest interviewer request with no separate extraction call/classifier.
- Honest per-model context budget: oversized input fails with a visible error, never silent trim.
- Sessions persist locally per meeting, are restored from history, and are included in Markdown export; the CV is excluded from export.

## Live transcription and window handling

- Independent bounded scroll panes for the live transcript and the interview panel.
- Native window placement no longer changes shared ctypes function signatures used by pywebview dragging.
- Live native worker uses bounded alternating channel drains, conservative quiet-input handling with pre-roll, held-word finalization at real pauses, and per-channel honest lag. Source audio remains fully recorded throughout.
- Compatible native live sessions now use Nemotron's trained R=13 context: 1.04 seconds of lookahead replaces excessive tiny encoder jobs and reduces cumulative two-channel backlog. Older runtimes retain R=0; model/runtime assets and offline behavior stay compatible.
- Live lag now measures each channel against its newest captured audio. Pausing browser playback or a silent remote speaker no longer creates growing fake loopback delay; resuming leaves no permanent offset. Genuine captured backlog, pending audio, unanswered speech, and app-pause handling remain visible.

## Setup, accessibility, and workspace

- Clearer first-run guide with back-navigation preserving mic/path results; optional uninstall data removal defaults to keep.
- Keyboard/modal/dropdown focus fixes and recoverable task feedback that retains the prior summary on failure/cancel.
- New Summary, Q&A, Participation, and final-transcription tape presentations respecting reduced motion.
- Completed Q&A answers are atomically saved/restored with visible save failure.
- Raw-level silence gating in native offline, Nemotron replay, and WhisperX reduces silent-mic hallucinations while preserving quiet dynamic speech and timestamps.
- Localized Groq key/region/network preflight at selection and before decode.
- Release publishing now records release notes on a fresh releases-repo commit before tagging.

## Audit fixes (2026-10-09 fleet audit)

- Transport Play/Pause icons inherit the text color again, so they stay visible on the light theme's raised pause button.
- Six user-visible strings (recording hotkey labels, draft-saved toast, Markdown export button and toasts) are now actually translated in the 13 non-English locales.
- Removed 50 dead locale keys (including the stale `sidebar.confirmClearQuick` confirmation) and the never-read `output_dir` setting.
- `MODEL_SAMPLE_RATE`, the outbound HTTP User-Agent, and the interview prompt ceiling each have a single source (`config` / the analysis core) instead of private copies.
